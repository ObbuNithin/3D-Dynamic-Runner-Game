# 3D-Dynamic-Runner-Game 🎮
This is a project built to overcome the general quiz systems through a fun 3d runner game where the questions level is dynamic and its fun to play. It is built using unity software and requires basic understanding of unity and c#.

## 🎮 Gameplay Mechanics

### Core Rules
- Collect all six question marks to progress
- Fail to collect a question mark: Game Over
- Answer each question correctly within 15 seconds
- Incorrect answer or timeout: Game Over

## 🚀 Technologies

- **Game Engine:** Unity
- **Programming Language:** C#
- **Character Animations:** mixamo
- **Assets:** Unity Asset Store

## 🎯 Key Features

- Infinite running gameplay
- Quiz-based challenge system
- Time-sensitive question answering
- Progressive difficulty

## 🛠 Installation

### Prerequisites
- Unity 2022.3 LTS or later
- .NET Framework 4.7.1+

### Steps
1. Clone the repository
   ```bash
   git clone https://github.com/[YourUsername]/Infinite3DRunnerQuizGame.git
   ```
2. Open the project in Unity
3. Ensure all dependencies are imported
4. Build and run the game

## 🎲 How to Play

1. Launch the game
2. Start running automatically
3. Collect all question marks
4. Answer questions quickly and accurately
5. Survive as long as possible!
